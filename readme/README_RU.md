## 📖 Описание

Утилита для Windows, которая позволяет делать скриншоты **комбинациями кнопок** или **значениями осей** геймпада вместо клавиатуры — идеально для игр, перехватывающих мышь или работающих в полноэкранном режиме. Снимки сохраняются на диск или в буфер обмена, а встроенная **циклическая запись** держит последние секунды в памяти: **долгое нажатие** превращает яркий момент в MP4 — OBS не нужен. Кроме того, можно **назначить кнопки геймпада на клавиши или сочетания клавиатуры** — геймпад превращается в панель горячих клавиш.

- ✅ Запуск комбинацией кнопок или значением оси (крестовина, L2 / R2…)
- ✅ Дополнительный триггер с клавиатуры
- ✅ Съёмка всего экрана (с выбором монитора) или отдельного окна
- ✅ Сохранение в файл, буфер обмена или оба варианта — JPG / PNG
- ✅ Свободные шаблоны имён: `%activeWinTitle%`, `%timestamp%`, `%datetime%` …
- ✅ Обработка конфликтов имён: перезапись / метка времени / не сохранять / спрашивать каждый раз
- ✅ Звуки скриншота — 5 встроенных звуков, регулировка громкости
- ✅ Оверлейное уведомление: настраиваемые положение, длительность и размер
- ✅ **Циклическая запись** — долгое нажатие сохраняет последние N секунд встроенным движком FFmpeg (NVENC / QSV / AMF / x264), OBS не нужен
- ✅ Настраиваемая длительность нажатия и миниатюра в уведомлении после сохранения
- ✅ Встроенный тест контроллера — кнопки, оси и крестовина подсвечиваются в реальном времени
- ✅ 9 языков интерфейса, тёмная / светлая темы, 6 акцентных цветов
- ✅ **Кнопки геймпада → клавиши клавиатуры** — одна кнопка или сочетание отправляет любую клавишу / комбинацию, включая Win и мультимедиа
- ✅ Три режима: Нажатие / Удержание / Повтор, порог и интервал настраиваются, каждое правило можно включать отдельно
- ✅ Клавиши добавляются по одной — при настройке не срабатывают системные сочетания
- ✅ Автозапуск, тихий запуск, сворачивание в трей, запуск прослушивания / маппинга при старте
- ✅ Обновления внутри приложения

## 🎮 Настройка комбинации клавиш

> **Примечание:** значения осей (направления крестовины, триггеры L2 / R2…) также можно использовать как триггеры. Ось считается «нажатой» только при значении выше **±0,85**.

1. Добавьте клавиши в карточке **Контроллер · Комбинация**. Какой физической кнопке соответствует каждый пункт, можно проверить во встроенном **тесте контроллера** — кнопка подсвечивается в реальном времени при нажатии.

<p align="center">
  <img src="images/shot-shortcut.png" alt="Настройка комбинаций" width="720" />
</p>

> **Совет:** у некоторых контроллеров номера кнопок меняются при подключении по Bluetooth — настраивайте комбинации по **USB**.

## ⌨️ Маппинг кнопок геймпада на клавиатуру

Удобно для действий, которые есть только на клавиатуре — переключение треков, рация, панель быстрых слотов — теперь с геймпада.

1. Откройте страницу **Маппинг** и нажмите **Запустить** справа сверху (для автозапуска включите **Настройки → Запускать маппинг кнопок при старте**).
2. Нажмите **Новое правило**, затем **Определить** на стороне геймпада и зажмите кнопку — несколько одновременно дают сочетание.
3. На стороне клавиатуры нажмите **Добавить клавишу** и вводите клавиши по одной (модификаторы первыми: Ctrl / Shift / Alt / Win). × на клавише удаляет её.
4. Выберите режим в строке: **Нажатие** / **Удержание** (порог в «Порог удержания») / **Повтор** (интервал в «Интервал повтора»).
5. Включите **Журнал** в разделе «Последние срабатывания», чтобы видеть попадания в реальном времени.

> **Примечание:** маппинг только отправляет клавиши и не блокирует исходный ввод геймпада — игра его по-прежнему получает. Для блокировки нужен драйвер виртуального геймпада (например, ViGEm / HidHide).

## 🔁 Циклическая запись

Здесь запись — это не «старт → стоп»: движок постоянно держит **последние секунды** в памяти, пока идёт прослушивание, и пишет на диск только по долгому нажатию.

1. Откройте страницу **Снимок** и переключите **Циклическую запись** в **Вкл** в разделе *Источник снимка*.
2. Чуть ниже выберите секунды **долгого нажатия** (0,5 / 0,8 / 1 / 1,5 / 2 / 3 с): удерживайте комбинацию столько — и запись сохранится; отпустите раньше, и будет обычный снимок.
3. В **Настройках** можно настроить кодировщик (NVENC / QSV / AMF / x264), разрешение, fps, качество или битрейт, длину буфера и лимит памяти.
4. Сомневаетесь, не будет ли пропусков кадров? Запустите **Проверку производительности кодировщика** — она реально пишет и кодирует, показывая пропущенные кадры и запас.
5. Сохранённые MP4 лежат в той же папке и по тому же шаблону имени, что и снимки, а сохранение подтверждает уведомление с **миниатюрой**.

> **Примечание:** источник записи следует за **Целью снимка** — экран пишет весь монитор, окно только это окно. Буфер работает только во время прослушивания.

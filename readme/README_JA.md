## 📖 はじめに

キーボードの代わりにゲームパッドの**ボタン組み合わせ**や**軸の値**でスクリーンショットを撮れる Windows ツールです。マウスを奪うゲームやフルスクリーン動作のゲームに最適。ファイルやクリップボードに保存できるほか、WebSocket 経由で **OBS** に接続して任意のシーンをキャプチャすることもできます。さらに**パッドのボタンをキーボードのキーやコンボに割り当て**、パッドをショートカットパッドとして使えます。

- ✅ ボタンの組み合わせ / 軸の値（十字キー、L2 / R2 など）でトリガー
- ✅ 追加のキーボードトリガー
- ✅ フルスクリーン撮影（撮影する画面を選択可能）／ウィンドウ単位の撮影
- ✅ ファイル・クリップボード・両方に保存 — JPG / PNG
- ✅ ファイル名テンプレートを自由に設定：`%activeWinTitle%`、`%timestamp%`、`%datetime%` など
- ✅ ファイル名の競合処理：上書き / タイムスタンプを付加 / 保存しない / 毎回確認
- ✅ スクリーンショット効果音 — 内蔵 5 種類、音量調整可能
- ✅ オーバーレイ通知（位置・表示時間・サイズを設定可能）
- ✅ **OBS-WebSocket** 連携で任意の OBS シーンをキャプチャ
- ✅ ショートカットの長押しで **OBS のリプレイバッファー**をクリップとして保存
- ✅ 内蔵コントローラー診断 — ボタン・軸・十字キーがリアルタイムに点灯
- ✅ 9 言語の UI、ダーク / ライトテーマ、6 色のアクセントカラー
- ✅ **パッドのボタン → キーボードのキー** —— 単押し／組み合わせで任意のキー・コンボを送信。Win キーやメディアキーにも対応
- ✅ トリガーは 3 種類：押下 / 長押し / 連射。しきい値と間隔を調整でき、ルールごとに有効化できる
- ✅ キーボード側は 1 キーずつ登録するため、組み合わせを録画してもショートカットを誤爆しない
- ✅ スタートアップ登録、サイレント起動、トレイに格納、起動時にスクリーンショット待機 / ボタンマッピングを実行
- ✅ アプリ内アップデート

## 🎮 組み合わせボタンの設定方法

> **メモ:** 軸の値（十字キーの方向、L2 / R2 など）もトリガーに使えます。軸は **±0.85** を超えた場合のみ「押された」と判定されます。

1. **コントローラー · ショートカット**カードでキーを追加します。どの物理ボタンに対応しているかは、内蔵の**コントローラー診断**ページで確認できます。ボタンを押すとリアルタイムに点灯します。

<p align="center">
  <img src="images/shot-shortcut.png" alt="ショートカット設定" width="720" />
</p>

> **ヒント:** 一部のコントローラーは Bluetooth 接続でボタン番号が変わります。ショートカットの設定は **USB 有線接続**で行うのがおすすめです。

## ⌨️ パッドのボタンをキーボードに割り当てる

曲送り、ボイスチャット、ホットバーなど、キーボードでしか操作できない動作をパッドから実行できます。

1. 左側の **マッピング** ページを開き、右上の **開始** を押します（起動時から動かすなら **設定 → 起動時にボタンマッピングを実行** をオン）。
2. **新規マッピング** を押し、パッド入力側の **検出** を押してからパッドのボタンを押します。同時に複数押すと組み合わせになります。
3. キーボード出力側の **キー追加** を押し、キーを 1 つずつ押します（Ctrl / Shift / Alt / Win などの修飾キーを先に）。キーキャップの × で削除できます。
4. 各行の右側でトリガーを選択：**押下** / **長押し**（しきい値は「長押し時間」）/ **連射**（間隔は「連射間隔」）。
5. 「最近の実行」の **記録** をオンにすると、どのルールが動いたかリアルタイムで確認できます。

> **補足：** マッピングはキーを送るだけで、パッドの元の入力を止めることはできません。ゲームにはパッドの入力も届きます。止めたい場合は ViGEm / HidHide などの仮想パッドドライバーが必要です。

## ⚙️ OBS でキャプチャする

1. OBS で **WebSocket サーバー**を手動で有効にします（通常は「ツール」メニューにあります）。
2. **スクショ**ページを開き、**キャプチャ方法**を **OBS** に切り替えます。OBS 接続パネルが下に展開されます。

<p align="center">
  <img src="images/shot-obs.png" alt="OBS 接続" width="720" />
</p>

3. OBS サーバーの**アドレス**（`ws://IP:ポート`）と**パスワード**を入力します。
4. 「**OBS に接続**」をクリックします。
5. 接続できたら、ドロップダウンからキャプチャしたい**シーン**を選択します。
6. ショートカットを押してシーンを撮影します。「長押しでリプレイを保存」を有効にしている場合、**長押し**で OBS のリプレイバッファーをクリップとして保存できます。
